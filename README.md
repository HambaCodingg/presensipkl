## Laporan kegiatan PKL

Jalankan `database/migration_laporan_kegiatan.sql` satu kali pada database `db_presensi`
sebelum menggunakan laporan baru. Migrasi menambahkan nama pembimbing siswa, tempat
kegiatan, dan penyimpanan tanda tangan per siswa serta rentang tanggal. Isi nama
pembimbing dan tempat kegiatan melalui formulir administrasi/siswa setelah migrasi.
